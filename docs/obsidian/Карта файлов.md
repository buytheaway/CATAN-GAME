## Основные переходы

S2B-1: [scenario.py](../../app/engine/scenario.py) owns explicit scenario parsing/setup capacity/settlement award bookkeeping; ScenarioRules/ScenarioState live in shared [state.py](../../app/engine/state.py). Existing rules.py calls them, legal.py probes the same executor, and trusted snapshots.py v3 persists the ledger. Details — [[Игровой движок#Explicit scenario execution — S2B-1]], [[Состояние игры#Scenario persistence — S2B-1]].

| Что изучаю | Начальный файл | Связанная заметка |
| --- | --- | --- |
| Создание комнаты в браузере | `web/src/components/LobbyPage.tsx` | [[Web клиент]] |
| Кнопка Roll | `web/src/components/GamePage.tsx` | [[Сценарий сетевой партии]] |
| Клик по дороге | `web/src/components/BoardView.tsx` | [[React интерфейс]] |
| Команда на сервере | `app/server_mp.py` | [[Сервер и протокол]] |
| Проверка стоимости и хода | `app/engine/rules.py` | [[Игровой движок]] |
| Положение фигур | `app/engine/state.py` | [[Состояние игры]] |
| Создание карты | `app/engine/maps.py` | [[Карты и сценарии]] |
| Острова и берег готовой карты | `app/engine/topology.py` | [[Карты и сценарии]], [[plans/seafarers-s2a]] |

`app/rules_engine.py` реэкспортирует API общего движка. Это не отдельная основная реализация правил. Browser BoardView рисует собственный SVG и не импортирует desktop-фигуры из `app/assets`.
