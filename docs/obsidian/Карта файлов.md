## Основные переходы

S2B-1: [scenario.py](../../app/engine/scenario.py) owns explicit scenario parsing/setup capacity/settlement award bookkeeping; ScenarioRules/ScenarioState live in shared [state.py](../../app/engine/state.py). Existing rules.py calls them, legal.py probes the same executor, and trusted snapshots.py persists the ledger (current v4; released v3 remains readable). Details — [[Игровой движок#Explicit scenario execution — S2B-1]], [[Состояние игры#Scenario persistence — S2B-1]].

S2B-2B.1/2A: [exploration.py](../../app/engine/exploration.py) owns trusted fog validation, known-terrain predicates, route discoveries and rewards; rules.py owns pending Gold/continuation execution, maps.py the existing private recipe v2 assignment, snapshots.py unchanged v4/3 exact restoration. legal.py isolates full fog probes; match_rulesets.py/repositories.py permit explicit native-current internal commits while public gates stay closed. Public gameplay/rendering remain disabled; no second board/model. Details — [[plans/seafarers-fog]].

S2B-2B.2B: [public_projection.py](../../app/engine/public_projection.py) owns closed typed map/config/scenario/tile projections; [serialize.py](../../app/engine/serialize.py) adds pure `project_fog_player_dict`, while normal serializers keep the Fog gate. [server_mp.py](../../app/server_mp.py) has internal `_project_fog_snapshot` and rejects generic private broadcasts. [game_events.py](../../app/game_events.py) produces committed discovery facts and projects closed per-kind/per-recipient fields; [net_protocol.py](../../app/net_protocol.py) filters room metadata. Recent/Active JSON map-name reads in repositories.py/auth/routes.py preserve native type for [inspection.py](../../app/persistence/inspection.py)'s safe DTO. Codec/recovery/rules/React/Board3D are unchanged; public Fog remains disabled. Tests — [test_fog_projection.py](../../tests/test_fog_projection.py), [test_fog_projection_recovery.py](../../tests/test_fog_projection_recovery.py).
