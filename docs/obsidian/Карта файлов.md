## Основные переходы

Public Fog Beta Phase 1 (2026-10-18; verification completed; results and limits in Project State): [fog_beta.py](../../app/fog_beta.py) owns strict admission/emergency policy, safe descriptor and canonical provenance; [seafarers_fog_beta_2.json](../../app/assets/maps/seafarers_fog_beta_2.json) is the frozen recipe, not a public assignment. [server_mp.py](../../app/server_mp.py) connects ordinary selection/start/rematch/commands/publication without reusing test capabilities; [match_rulesets.py](../../app/match_rulesets.py) recognizes only verified `catan-fog-beta-1`, and [recovery.py](../../app/persistence/recovery.py) keeps exact restoration/Fog timers off. Existing Repository/codec/F1 paths remain authoritative. [LobbyPage.tsx](../../web/src/components/LobbyPage.tsx), [RoomSettings.tsx](../../web/src/components/RoomSettings.tsx) and [LegacyMatchPage.tsx](../../web/src/components/LegacyMatchPage.tsx) explain the limited profile/settings/pause. Pure tests — [test_fog_beta_policy.py](../../tests/test_fog_beta_policy.py); actual TCP/PG support and acceptance — [fog_beta_support.py](../../tests/fog_beta_support.py), [test_fog_beta.py](../../tests/test_fog_beta.py); Chrome runner — [fog-beta.cjs](../../web/e2e/fog-beta.cjs). Admission is disabled by default; legacy internal Fog remains closed. [[plans/seafarers-fog#Public Beta Phase 1 — authorized implementation, 2026-10-18]]. Dated paragraphs below are earlier implementation checkpoints.

S2B-1: [scenario.py](../../app/engine/scenario.py) owns explicit scenario parsing/setup capacity/settlement award bookkeeping; ScenarioRules/ScenarioState live in shared [state.py](../../app/engine/state.py). Existing rules.py calls them, legal.py probes the same executor, and trusted snapshots.py persists the ledger (current v4; released v3 remains readable). Details — [[Игровой движок#Explicit scenario execution — S2B-1]], [[Состояние игры#Scenario persistence — S2B-1]].

S2B-2B.1/2A: [exploration.py](../../app/engine/exploration.py) owns trusted fog validation, known-terrain predicates, route discoveries and rewards; rules.py owns pending Gold/continuation execution, maps.py the existing private recipe v2 assignment, snapshots.py unchanged v4/3 exact restoration. legal.py isolates full fog probes; match_rulesets.py/repositories.py permit explicit native-current internal commits while public gates stay closed. Public gameplay remains disabled; fixture-tested rendering was added in .3A below, with no second game model. Details — [[plans/seafarers-fog]].

S2B-2B.2B: [public_projection.py](../../app/engine/public_projection.py) owns closed typed map/config/scenario/tile projections; [serialize.py](../../app/engine/serialize.py) adds pure `project_fog_player_dict`, while normal serializers keep the Fog gate. [server_mp.py](../../app/server_mp.py) has internal `_project_fog_snapshot` and rejects generic private broadcasts. [game_events.py](../../app/game_events.py) produces committed discovery facts and projects closed per-kind/per-recipient fields; [net_protocol.py](../../app/net_protocol.py) filters room metadata. Recent/Active JSON map-name reads in repositories.py/auth/routes.py preserve native type for [inspection.py](../../app/persistence/inspection.py)'s safe DTO. Codec/recovery/rules/React/Board3D are unchanged; public Fog remains disabled. Tests — [test_fog_projection.py](../../tests/test_fog_projection.py), [test_fog_projection_recovery.py](../../tests/test_fog_projection_recovery.py).

S2B-2B.3A: [publicTiles.ts](../../web/src/board/publicTiles.ts) sanitizes/classifies public tiles and public center/q/r coordinates; [fogReveal.ts](../../web/src/board/fogReveal.ts) owns committed-frame presentation baselines/expiry above the renderer selector. Existing BoardView/model/HexTile3D preserve graph IDs/controller; [FogVisual.tsx](../../web/src/board3d/FogVisual.tsx) owns neutral procedural Fog and finite ref-based reveal. [discovery.ts](../../web/src/game/discovery.ts) validates public discovery text and the personal Gold explanation; GamePage uses the existing ACK waiting. Tests: [fogRendering.test.mjs](../../web/tests/fogRendering.test.mjs), WS freshness, publicFog.ts fixture, test-only fog-fixture.tsx/[fog-rendering.cjs](../../web/e2e/fog-rendering.cjs). Python/public Fog gates/GLB/audio remain unchanged. [[React интерфейс#Public Fog presentation — S2B-2B.3A]].

S2B-2B.3B: [fog_transport.py](../../app/fog_transport.py) defines the immutable in-process room/match fixture capability; server_mp.py validates it for internal commands/safe snapshots and keeps the existing lock/candidate/COMMIT/receipt/F1 publisher. net_protocol.py permits scoped WS compatibility metadata only; default startup/HTTP/public selection/start/rematch/timers remain restricted. [fog_live_support.py](../../tests/fog_live_support.py) is the guarded isolated launcher/actual TCP test support, not copied into production. [test_fog_live.py](../../tests/test_fog_live.py), [test_fog_live_privacy.py](../../tests/test_fog_live_privacy.py) and [fog-live.cjs](../../web/e2e/fog-live.cjs) cover wire authority/privacy/recovery and real Chrome. Docker's explicit COPY includes only the new runtime module. No rules/codec/React renderer change; public Fog disabled. [[Сервер и протокол#Internal Fog live transport — S2B-2B.3B]].

Natural Fog acceptance (2026-10-17): [fog_natural_support.py](../../tests/fog_natural_support.py) reuses `full_match_support`'s subprocess/owning clients/cooperative player, admits only its privately bound test lobby's lifecycle and audits committed rewards/VP/resources. [test_fog_natural.py](../../tests/test_fog_natural.py) validates normal opening→victory→recovery→fresh Fog rematch and rejected host/epoch/public admission. [fog-natural.cjs](../../web/e2e/fog-natural.cjs) reuses existing browser helpers against the real production frontend. All are test-only; no production import or new endpoint. [[Project State]], [[plans/seafarers-fog]].
