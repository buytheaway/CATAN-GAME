# Точки входа

[[00 Главная]] · [[Карта файлов]]

| Часть | Вход | Кто вызывает | Результат |
| --- | --- | --- | --- |
| Desktop | [main_menu.py](../../app/main_menu.py): `main()` | `RUN_UI_V6.bat`, `RUN_CLIENT.bat`, `python -m app.main_menu` | QApplication и MainMenuWindow |
| Локальная партия | [game_launcher.py](../../app/game_launcher.py): `start_game(config, on_back_to_menu)` | MainMenuWindow._launch_game | Создаёт, показывает и возвращает ui_v6.MainWindow |
| Web | [main.tsx](../../web/src/main.tsx) | Модульный script из web/index.html | Монтирует App в #root |
| Сервер | [server_mp.py](../../app/server_mp.py): `main()` | RUN_SERVER.bat или `python -m app.server_mp` | Запускает Uvicorn с FastAPI app |
| WebSocket endpoint | `websocket_endpoint(ws)` | FastAPI при подключении к /ws | Принимает соединение и обрабатывает сообщения |
| Создание игры | [rules.py](../../app/engine/rules.py): `build_game(...)` | Сервер _start_match или desktop build_board | Возвращает GameState |
| Выполнение действия | `apply_cmd(g, pid, cmd)` | Сервер _apply_cmd, desktop и тестовый driver | Меняет g, возвращает `(g, events)` или поднимает RuleError |

У движка нет собственного бесконечного цикла или отдельного процесса. Это Python-библиотека, которую вызывают [[Desktop клиент]] и [[Сервер и протокол]].

В web `npm run dev` запускает Vite; `npm run build` собирает browser-файлы. Vite не исполняет Python-правила.
