# Карты и сценарии

[[Игровой движок]] · [[Правила Seafarers]]

Карты лежат в [app/assets/maps](../../app/assets/maps). Основные функции находятся в [engine/maps.py](../../app/engine/maps.py): get_preset_map, list_presets, load_map_file, validate_map_data, build_board_from_map.

## Два формата

В исходном JSON карта задаётся гексами: `q`, `r`, `terrain`, `number`. `q/r` — axial-координаты гекса. При построении появляются центры, вершины, рёбра и adjacency-таблицы. Клиент получает уже подготовленную геометрию.

```json
{"q": 0, "r": -2, "terrain": "forest", "number": 6}
```

`terrain: "random"` и `number: "random"` выбирают значения из соответствующих колод. Порты могут быть явными либо автоматическими.

Параметры rules: target_vp, лимиты фигур, robber_count, enable_seafarers, enable_pirate, enable_gold, enable_move_ship. parse_rules_config преобразует их в RulesConfig.

Полная действующая документация формата: [maps_schema.md](../maps_schema.md).

## Пути выбора

- Desktop offline: пресет или map_path в GameConfig → build_board → build_game.
- Multiplayer: host отправляет set_map → Room хранит выбранные данные → _start_match передаёт их в build_game.
- Web: LobbyPage показывает map_presets и загружает пользовательский JSON через FileReader.

Exploration/fog и награды островов из [[Спецификация пользователя]] — требования сценариев. В текущей модели нельзя считать их реализованными только по наличию enable_seafarers.
