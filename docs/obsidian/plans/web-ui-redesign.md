# Goal

Подготовить и затем реализовать новый React UI по согласованным references, сохраняя игровой протокол и поведение. Текущая задача разрешает только документационную подготовку.

# Current State

[[React интерфейс]]: App → LobbyPage или GamePage → BoardView. Ресурсы/игроки/формы — встроенные JSX-блоки. Оригинальные references сохранены и разобраны в [[Design System]]: gameplay (два уникальных варианта), lobby/menu, modals, settings, rules/help. Окончательное решение ещё не принято.

# Files / Systems Affected

Сейчас: Design System и docs/design/references. При будущей реализации: web/src/App.tsx, components/*.tsx, styles.css, BoardView.constants/types/utils. WebSocket и engine затрагивать только при отдельно определённой необходимости, а не по визуальному концепту.

# Invariants That Must Not Break

Сохранить payload команд, ID геометрии, роли host/игрока, доступность действий по фазе, pending-action и server authority. Локальный выбор инструмента не меняет игровое состояние. Макет не утверждает новую механику автоматически.

# Implementation Steps

1. Выполнено: сохранить полученные оригиналы и описать каждый уникальный reference, состояния и концептуальные детали.
2. Согласовать композицию и visual tokens в Design System.
3. Сопоставить блоки с текущими props, callbacks и ограничениями.
4. После отдельного запроса на реализацию менять UI небольшими шагами по экрану/состоянию.
5. Проверить сетевые сценарии и визуальные состояния; обновить документацию.

# Validation

До реализации: реальные пути references, корректные ссылки, явные статусы concepts. После реализации: type-check/build и профильные проверки; два клиента проходят lobby/setup/roll/build/end, discard/gold; клики соответствуют геометрии; адаптивная раскладка сохраняет действия и информацию. Фактические результаты записывать только после выполнения.

# Status

Draft. Оригиналы получены и reference-analysis выполнен. Дизайн не утверждён; React/PySide/CSS не менялись. Ни один шаг реализации UI не выполнен.
