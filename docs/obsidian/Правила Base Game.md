# Правила Base Game

Источник: [[Спецификация пользователя]]. Это требования к игре, не описание гарантированного поведения текущего кода.

## Цель и ресурсы

Стандартная цель — 10 VP, сценарий может задать другую. Победа устанавливается в ход победителя. Очки дают постройки, достижения и скрытые VP-карты.

| Код проекта | Название в спецификации | Местность |
| --- | --- | --- |
| wood | Lumber | Forest |
| brick | Brick | Hills |
| sheep | Wool | Pasture |
| wheat | Grain | Fields |
| ore | Ore | Mountains |

Пустыня не производит. Банк ограничен; количество ресурса не должно становиться отрицательным.

## Расстановка

Запас фигур: 5 поселений, 4 города, 15 дорог. Начальные пары поселение+дорога ставятся «змейкой»: 1→2→3→4→4→3→2→1. Дорога соединена с только что поставленным поселением. После второго поселения игрок получает по ресурсу от каждой прилегающей производящей клетки. Правило расстояния действует и при setup.

Принято пользователем для multiplayer **2026-10-06**: «первый» не означает pid=0/P1 или определённый цвет. Сервер выбирает стартующего по room policy Random (default) или Host. Snake поворачивается от него; при 4 игроках и starter pid=2 это 2→3→0→1→1→0→3→2. Он же начинает main, rematch выбирает снова по policy. Offline default starting_pid=0 сохраняется. Дополнительные разрешённые room options — [[Спецификация пользователя#Multiplayer room options — accepted 2026-10-06]]; они не меняют стоимости/production/dev rules.

## Ход

1. Две шестигранные кости. При результате не 7 соответствующие клетки производят: поселение получает 1, город 2.
2. При 7 игроки с более чем threshold картами сбрасывают половину с округлением вниз. Threshold=7 по умолчанию; multiplayer host может настроить его до Start (принято пользователем 2026-10-06 в Game UX 2.3). Затем активный игрок переносит разбойника на другую допустимую сухопутную клетку и может украсть случайную карту у подходящего соседа.
3. Торговля и строительство в допустимом порядке.
4. Конец хода, следующий игрок.

Разбойник блокирует производство своей клетки. Поселения и города должны иметь между собой минимум два ребра; соседние вершины заняты быть не могут.

## Стоимость

| Действие | Ресурсы |
| --- | --- |
| Дорога | 1 wood + 1 brick |
| Поселение | 1 wood + 1 brick + 1 sheep + 1 wheat |
| Город | 3 ore + 2 wheat |
| Development card | 1 ore + 1 sheep + 1 wheat |

Дорога продолжает допустимую сеть. Поселение соединено со своей дорогой, кроме setup. Город заменяет своё поселение; фигура поселения возвращается в запас.

## Торговля

Только активный игрок инициирует domestic trade. Ресурсы нельзя отдавать за ничего. Банк: 4 одинаковых → 1 выбранный; обычный порт 3:1; специализированный 2:1 для указанного ресурса. Порт доступен через своё поселение/город на его вершине.

## Карты развития и достижения

- Knight: разбойник и кража, учитывается для Largest Army.
- Road Building: две бесплатные дороги; Seafarers-вариант зависит от правил сценария.
- Year of Plenty: два доступных ресурса банка.
- Monopoly: все карты выбранного типа от остальных игроков.
- Victory Point: скрытое очко, раскрываемое для установления победы.

Новую карту обычно нельзя сыграть в тот же ход. Обычно разрешена одна development card за ход, кроме раскрытия VP. Ошибка не должна расходовать карту.

Longest Road: от пяти сегментов, 2 VP, чужая постройка может прервать маршрут. Ничьи следуют настроенному официальному правилу. Largest Army: от трёх рыцарей, 2 VP; при ничьей квалифицированный владелец сохраняет награду, новый владелец должен строго превысить его результат. Ничья без владельца не назначает награду произвольно.

Largest Army enforcement исправлен отдельным focused patch 2026-10-09: real Knight commands/turns в Base и Seafarers, +2 VP без повторного начисления, собственный ход победителя и сохранение исторических VP/achievement без пересчёта проверены. Результаты — [[Project State#Largest Army tie handling — focused correctness fix]]. Это исправление реализации существующего требования, не изменение спецификации.
