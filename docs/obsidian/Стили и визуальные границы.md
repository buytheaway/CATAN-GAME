# Стили и визуальные границы

## Terrain GLB visual boundary — 2026-10-07

Primary terrain art now lives in the eight unchanged `web/public/models/terrain/*.glb` assets, selected/placed by [TerrainHexVisual.tsx](../../web/src/board3d/TerrainHexVisual.tsx) and [terrainAssets.ts](../../web/src/board3d/terrainAssets.ts). Common scale/orientation/lift affect presentation only. Procedural terrain files remain local loading/error fallback; ownership colors, HUD/CSS, logical hex/vertex/edge targets and pieces remain separate.

NumberToken3D and the visual resource pool render number badges/hex feedback over relief without changing tile IDs, anchor coordinates or GLB materials. Conservative camera heights include the new relief; surrounding DecorativeOcean stays static decoration. 169 web tests/TS/build and production Chrome Base/Gold hover/placement/camera/reconnect/fallback passed; measured GPU cost and limits — [[plans/board3d#Terrain GLB integration — visual scope]]. Earlier procedural visual descriptions below retain their historical dates.

## Связь с поведением

| Часть | Что можно менять в оформлении | Какие связи сохранять |
| --- | --- | --- |
| Заголовок, фон, карточки | Цвет, шрифт, отступы, границы | Отображение вложенного содержимого |
| Ресурсы | Вид карточки, подпись, расположение | Ключ ресурса k и количество res[k] |
| Список игроков | Вид строки, маркеры, расположение | pid, name, vp/connected/host |
| Статус и журнал | Типографика, контейнер, раскладка | Исходные значения, тексты ошибок |
| Формы | Внешний вид контролов | value, onChange, min/max и обработчик отправки |
| Кнопки | Цвет, размер, подпись | onClick и disabled |
| Поле | Изображение фигур и клеток | Геометрия, ID, hit areas, порядок SVG-слоёв, клики и legal |

GamePage и LobbyPage сохраняют связи с командами/сетевыми действиями. BoardView и Board3D после Phase 2 используют renderer-neutral interaction props: визуальную часть можно менять, сохраняя оригинальные IDs, target membership и callbacks. Shared controller не рассчитывает gameplay rules. Простые текстовые панели и карточки ресурсов имеют меньше поведенческих связей.

В constants лежат также ActionType, CommandType, GamePhase и SETUP_TYPES. Эти значения участвуют в поведении; они не являются визуальными токенами. `edgeKey` связывает данные дороги с ключом occupied_e; `hexCorners` и `calculateBounds` связывают рисунок с геометрией.

Props поля описаны в [BoardView.types.ts](../../web/src/components/BoardView.types.ts). Типы — описание контракта, а не runtime-валидация. Известные несоответствия контракта отмечены в [[Результаты аудита]].

2026-10-02: несоответствия Port и состояния исправлены при согласовании приватного network view, TypeScript проходит. CSS/SVG и визуальная композиция React не менялись. Runtime validation сетевого JSON остаётся отдельным ограничением клиента.
