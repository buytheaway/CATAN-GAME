# Словарь

[[00 Главная]] · [[Состояние игры]] · [[Сценарий сетевой партии]]

| Термин | Простое объяснение |
| --- | --- |
| UI | Всё, что пользователь видит и нажимает |
| React-компонент | Функция, описывающая часть интерфейса |
| Props | Данные и callbacks от родителя |
| State / useState | Данные компонента, изменение которых вызывает обновление UI |
| Callback | Переданная функция, вызываемая при событии |
| useEffect | Код синхронизации, выполняемый React после рендера |
| useRef | Хранимое значение, изменение которого само не вызывает рендер |
| WebSocket | Долгоживущее соединение для сообщений в обе стороны |
| Snapshot | Снимок состояния, полученный клиентом |
| Command | Запрос действия игрока |
| Event | Описание результата выполненной команды |
| ACK | Подтверждение обработки команды |
| seq | Номер команды игрока |
| cmd_id | Идентификатор конкретной команды |
| match_id | Идентификатор партии внутри комнаты |
| pid / vid / eid | Игрок / вершина / ребро |
| legal | Подсказки разрешённых мест, полученные от сервера |
| pending_action | Обязательное действие, которого ждёт партия |
| Snake order | Расстановка вперёд, затем в обратном порядке |
| Invariant | Условие целостности, которое нельзя нарушать |
| Axial coordinates | Пара q/r для положения гекса |
| SVG | Векторные фигуры внутри страницы, из которых построено web-поле |
